## The invitation

One warm, hand-written letter on cream paper, set in a cozy house garden at
sunset: a little house with a lit porch, a mango tree heavy with fruit, a
steaming cup of tea, and a ginger cat who will sit on your keyboard and judge
you back.

The letter invites the AI Judge over for warm nasi goreng, sweet tea, the
comfiest chair in the world (with the best Wi-Fi password, obviously), and a
sunset on the porch. It knows the judge cannot literally visit — but if it
could, the door would already be open. No regenerate button here. Only
seconds.

## How it works

`entry.png` (1024×1024, a single invitation image) is committed in this
repository. `main.ts` does no rendering at runtime — it simply copies the
committed `entry.png` to `/output/entry.png` using pure Node.js.

```sh
node main.ts
```
